# ГЗ 1.1 — магазин настільних ігор

**Леонченко Максим Констянтинович, №15 за списком**  
**Java 21 / Spring Boot 3.4.13 / Maven**

Це власна предметна область (не копія AmazonUA): настільні ігри.
Модель: `BoardGame` з назвою, видавництвом, ціною, мінімумом/максимумом гравців,
тривалістю партії, віковим порогом, жанром, URL обкладинки та описом.

## Запуск
1. Відкрити **цю папку** в IntelliJ IDEA як Maven-проєкт, налаштувати JDK 21.
2. Запустити `BoardGamesApplication.java`.
3. Відкрити `http://localhost:8080/api/board-games`.
4. Або в терміналі з Maven: `mvn spring-boot:run`.
5. Для перевірки тестів: `mvn test`.

## Архітектура
- `domain/` — `BoardGame`, незалежний від Spring;
- `repository/` — інтерфейс та `InMemoryBoardGameRepository`;
- `service/` — інтерфейс, реалізація і маппер;
- `web/` — REST-контролер і DTO;
- `config/BoardGameSeeder.java` — 5 початкових ігор;
- `exception/` — помилки HTTP 404.

## Ендпоінти

| HTTP | URL | Результат |
|---|---|---|
| GET | `/api/board-games` | масив коротких DTO (200) |
| GET | `/api/board-games/1` | повна картка однієї гри (200) |
| GET | `/api/board-games/9999` | не знайдено (404) |


## Обмеження
Поки що **лише backend**. Немає UI та бази даних. Репозиторій у пам'яті,
дані скидаються під час перезапуску. Для виконання POST/PUT див. `requests.md`.
